# Member Home

The approved Home separates profile cards from circle cards. Existing icons, colours and navigation are retained. Create and Join circle entry points are in Settings; Home only displays circles returned by the authenticated circle snapshot. The My Circle navigation item still requires real membership.

A normal login opens `/member/home` with the account's own authorised profile selected. Explicit invitation and return destinations remain intact. Clicking a card selects one authorised profile or the intersection of a circle's attached profile IDs and the current account's active profile access. Same names and email addresses never connect records. A circle does not reveal members who have not been shared. Selection is scoped to the current user in session storage and checked against each fresh snapshot. Opening My Activities from Home keeps that selection; explicit production/profile/circle links are validated in the same way. Organisation management remains accessible from Settings and its original routes.

The calendar supports weeks, months and Previous/Today/Next. Existing safe audition session/slot views supply booked audition dates. Existing volunteer records supply shifts, including each explicit required date of a multi-date commitment. The safe production-event view supplies the requested calendar period, filtered to the productions of selected profiles. Production events are labelled as such; the account response does not establish that every member has been called. Month and week requests are cached for the current response generation, and stale asynchronous results cannot overwrite a newer account response or selection. Event-loading failures are shown rather than claiming the schedule is complete.

Needs your attention includes role offers, incomplete registrations, account profile-access tasks and due/overdue payment reminders. Read-only `bts_family_tracker` and the existing payment projection are reused. Shared invoice IDs are deduplicated. Fully paid or later instalments are excluded; reminders include overdue instalments and those due within the next seven days. Older unconfirmed payment logs prompt review without asserting an outstanding balance. There is no payment collection or payment splitting. Tracker failures have a visible schedule link.

Records without a profile ID are not assigned by name. Home offers a link to review older records. No new database tables, policies, functions or migrations were needed.

Verification: `member-home.test.cjs` covers profile/circle filtering, inaccessible and revoked members, unlinked records, own-profile defaults and reminder calculation. `member-home-browser.cjs` exercises actual pages with synthetic APIs: card selection, dependent data, due reminders, audition times, month navigation, login defaults, individual navigation and phone/tablet/desktop widths. Existing unified-account, Circle and URL browser/route tests remain in use. No real invitation emails or account data are written by these tests.
